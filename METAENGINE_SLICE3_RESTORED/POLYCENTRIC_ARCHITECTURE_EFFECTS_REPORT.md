# Polycentric Architecture Effects Report — METAENGINE 16X 1.4.0-alpha.1

## Purpose

Version 1.4 extends the 1.3 Core-4 recursive weave to a **polycentric recursive ecology of all sixteen engines**. The experiment is deliberately evaluated as an architectural/procedural intervention: a useful effect is recorded only when a recurrent cross-engine transformation is observed without creating new truth-bearing native positions.

Claim ceiling:

`CONTROLLED_POLYCENTRIC_RECURSIVE_ARCHITECTURAL_AND_PROCEDURAL_GAIN_WITH_NATIVE_TRUTH_POSITION_INVARIANCE; NOT_EXTERNAL_PHILOSOPHICAL_OR_SEMANTIC_SUPERIORITY_VALIDATION`

## Runtime change

The 1.3 Core-4 deep weave is retained intact. Version 1.4 adds:

1. **round 1 — ALL16 re-entry:** every engine receives the shared hybrid state and architecture-specific return pressure;
2. **round 2 — ALL16 peer re-entry:** every engine receives selected causal returns from peer architectures;
3. **round 3 — novelty gated:** at most eight engines continue, selected by incremental novelty rather than fixed prestige or voting weight;
4. **adaptive stop:** recursion terminates when the new round no longer changes the architectural situation enough to justify another pass.

All polycentric returns are capped at `GENERATIVE_ONLY` / `SECOND_ORDER_GENERATIVE` until independently grounded on original source material.

## Controlled five-case result

Five held-constant tasks were used: hermeneutic ambiguity, evidence conflict, memory/history, graph/workflow, and mixed research.

- completed: **5/5**;
- primary native claim-node invariance: **5/5**;
- primary native claim-position invariance: **5/5**;
- derived truth-promotion violations: **0/5**;
- nonnegative preservation of pre-1.4 structural edges: **5/5**;
- adaptive stop reached: **5/5**;
- useful effects activated: **10/10 in all five cases**.

Across the five runs the polycentric layer generated:

- **728** second-order generative positions;
- **392** observed causal peer-pair participations;
- **896** re-entry probes entering the hybrid mesh;
- research agenda growth from **156 → 197** items in aggregate;
- no new native truth-bearing positions.

## Novelty dynamics

Every benchmark used two complete all-16 rounds and a third gated round of eight engines.

Round-2 incremental novelty was approximately **0.545–0.572**. Round-3 novelty collapsed to approximately **0.012–0.053**, and all five runs stopped with `ADAPTIVE_NOVELTY_STOP`.

This is a useful effect in its own right: the system can distinguish recursive transformation from recursive repetition. Earlier gate logic accidentally rewarded the mere existence of peer context; 1.4 was corrected so only **new peer dependencies** count as novelty.

## Emerging specialization without fixed weights

The novelty-gated third round exposes a first empirical specialization pattern.

Selected in **5/5** benchmark cases:

- Engine 3 — semantic-boundary differential;
- Engine 5 — persistent memory / hysteresis;
- Engine 8 — critical-point replanning;
- Engine 11 — workflow-order counterfactual;
- Engine 12 — checkpoint/state replay;
- Engine 14 — perspective expansion.

Selected in **3/5**:

- Engine 1 — destructive/interrogative pressure;
- Engine 2 — operator mutation/ecology.

Selected in **2/5**:

- Engine 9 — gap reopening / citation dependency;
- Engine 10 — workforce recomposition.

The other engines still execute both complete all-16 recursive rounds. Their absence from round 3 means only that their **incremental** contribution had fallen below the top novelty set on these five tasks. No permanent reliability weight is inferred from this small sample.

## Monotonic mixing invariant

An early 1.4 run exposed a negative effect: adding new re-entry seeds could evict old research-agenda entries because of a bounded agenda limit, causing two pre-existing structural links to disappear.

The release was corrected to require **monotonic structural preservation**: new mixing may add or enrich agenda links, but cannot silently replace prior links merely because the queue becomes crowded.

Final five-case result: pre-1.4 native nodes/positions are preserved in every case and old structural-edge counts never decrease.

## Runtime cost

The gain is not free. In a three-run same-case local sample:

- 1.3 median: **2.1610 s**;
- 1.4 median: **3.1409 s**;
- observed median overhead: **+45.3%**.

This is a small local sample, not a stable performance benchmark. The result nevertheless confirms that polycentric recursion has a meaningful cost. Adaptive stopping is therefore an architectural necessity, not cosmetic optimization.

## Interpretation

The positive effect of 1.4 is not “more answers”. The truth-bearing native claim core remains invariant. The gain is instead a larger and more dynamically reorganized space of:

- questions;
- rival framings;
- memory-conditioned returns;
- graph/evidence dependencies;
- workflow alternatives;
- perspective expansions;
- hypothesis tests;
- counterfactual objections;
- explicit stopping decisions.

This supports a bounded conclusion: **all-sixteen architectural mixing produces controlled gains in recursive composition and self-revision while preserving the epistemic firewall of the native claim layer.** External philosophical depth, truth or semantic superiority still requires blind external evaluation.
