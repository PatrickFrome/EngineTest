## Эволюция 0.6 → 0.10

### 0.6 — source resistance

Corpus Refinery сравнивает source-backed centrality с покрытием curated registry. Registry blind spot создаёт `SOURCE_FORCED_REGISTRY_RESISTANCE`; только source-forced record может активировать GX7. PROJECT_CLAIM не является достаточным триггером method mutation.

### 0.7 — regression and forgetting

Source-born operator проходит origin/transfer/mixed/negative controls и получает retain/quarantine/retire lifecycle. Relation-sensitive analysis различает локальные профили, не превращая `RELATION_FIRST` в default ontology.

### 0.8 — competition and abstention

Source-born profiles конкурируют. Допустимы `SELECT_LOCAL_WINNER`, `LOCAL_COMPOSITION`, `KEEP_RIVALS_UNRESOLVED`, `ABSTAIN_UNRESOLVED`.

### 0.9 — executable genetic–ecological merge

Declarative runtime и mutation gate снова связаны с living engine. Candidate registry можно реально выполнить через `living-cycle --registry`; baseline registry не меняется, rollback обязателен.

### 0.10 — open-set hermeneutic discovery

Known vocabulary больше не является последней рамкой. Если source-central field остаётся unresolved, система может создать `UNKNOWN_OPERATOR_FAMILY` с micro-local source signature и rival unitizations. Новый mutation kind `ADD_OPERATOR` способен добавить такую conditional family в отдельный candidate registry.

`micro-local-ecology` работает на перекрывающихся argument windows и допускает:

- `KNOWN_PROFILE_LOCAL`;
- `OPEN_SET_LOCAL_CANDIDATE`;
- `KEEP_KNOWN_AND_OPEN_SET_RIVALS`;
- `ABSTAIN_LOCAL`.

## Controlled Descartes regression 0.10

Descartes cogito сохранён как negative relation-genesis case:

- baseline graph: 3 constellations / 101 nodes / 149 edges / 0 F-OPEN nodes;

Это internal architectural regression, не external semantic validation.

## Главный предел

Open-set discovery 0.10 использует lexical recurrence/co-occurrence и source centrality. Он ещё не различает в полном объёме predicate polarity, quotation/attribution, modality и argumentative role. Поэтому candidate может быть surface-dependent и должен оставаться reversible.

## Следующий этап

**0.11 — Adversarial Semantic Role / Anti-Self-Confirmation.**

Gate должен проверить `span → predicate → polarity → modality → attribution → argumentative role`, а также paraphrase, translation, negation, quoted-opponent и decoy perturbations. Candidate, который выживает только благодаря лексической поверхности, должен автоматически quarantine/retire.
