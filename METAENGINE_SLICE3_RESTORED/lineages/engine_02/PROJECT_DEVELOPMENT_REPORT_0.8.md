# Destruktion 4.0 — Project Development Report 0.8

## Revision thesis

Version `0.8.0-alpha.1` implements the next gate left open by 0.7: **operator competition / composition / abstention**. Cross-corpus transfer had shown that one experimental relation-genesis family could survive heterogeneous controls. That was still insufficiently nonlinear because the method could retain a successful family and route future corpora through it by default.

The 0.8 loop therefore becomes:

`source resistance → source-born operator profile → local competition → distinction gain / distortion loss → local winner | local composition | unresolved rivals | abstention`.

No local result is a global philosophical verdict and no competition result promotes an operator into frozen CORE.

## Source-born candidate audit

Competition candidates are not admitted merely because they were hand-written into a manifest. Each candidate must point back to an origin refinery and living run. Its required birth profile must be present in the origin hypothesis bank, and the source operator mutation must be present in the origin living trace. If either condition fails, the candidate is non-viable everywhere.

The first competition benchmark reuses four source-born profiles from the 0.7 resistant-source regression:

- Geviert → `CO_CONSTITUTIVE_OR_RECIPROCAL` plus optional `DIFFERENCE_PRESERVING_PROXIMITY`;
- Saussure → `DIFFERENTIAL_CONSTITUTION`;
- Spinoza → `ASYMMETRIC_DEPENDENCE`;
- Aristotle → `LOCAL_MODE_VARIATION`.

All four source-birth audits passed.

## Gain/loss rather than winner-takes-all

Each candidate is scored locally. Required source-profile matches add distinction gain; missing requirements and incompatible profiles add distortion loss; added profile complexity has a small cost. The score is an internal routing heuristic only.

The target decision space is deliberately non-binary:

- `SELECT_LOCAL_WINNER` — one candidate explains the available local operator profile without additional composition gain;
- `LOCAL_COMPOSITION` — two or more source-born candidates cover non-redundant local distinctions;
- `KEEP_RIVALS_UNRESOLVED` — available evidence does not justify selection;
- `ABSTAIN_UNRESOLVED` — the current operator ecology has no warranted local candidate.

The new capability is therefore not only choice but **refusal to choose** and **local combination without a global meta-ontology**.

## Five-target regression

| Target | Decision | Selected/composed |
|---|---|---|
| Heidegger — Geviert | `SELECT_LOCAL_WINNER` | Geviert co-constitutive gathering |
| Saussure — value/difference | `SELECT_LOCAL_WINNER` | differential constitution |
| Spinoza — substance/mode | `SELECT_LOCAL_WINNER` | asymmetric dependence |
| Aristotle — substance/relatives | `LOCAL_COMPOSITION` | asymmetric dependence + local mode variation |
| Descartes — cogito | `ABSTAIN_UNRESOLVED` | none |

All `5/5` preregistered target expectations passed. The Descartes case is especially important: a philosophically central, source-resistant corpus is now allowed to defeat the whole candidate ecology instead of receiving the least-bad operator.

## Why Aristotle matters

Aristotle is the first implemented composition case. `ASYMMETRIC_DEPENDENCE` captures the priority structure around primary substance, while `LOCAL_MODE_VARIATION` blocks the inference that every local relation in the corpus must instantiate the same dependence profile. Neither operator is allowed to become a universal account of the whole text. Their composition is explicitly local and revisable.

This shifts hermeneutic nonlinearity from multiple branches inside one model to **coexisting local models whose domains can overlap without being fused**.

## Epistemic nonlinearity

Version 0.8 separates at least five judgments:

1. the source resists the current registry;
2. a source-born operator profile is historically real as a project artifact;
3. that profile is locally useful on a target;
4. several profiles may add non-redundant distinctions;
5. none of this establishes the philosophical truth of the represented ontology.

The new abstention state is as important as mutation. Methodological openness now includes the possibility that the project has learned several useful forms of questioning and **none of them is locally warranted**.

## Remaining risks

- candidate signatures are still engineered from a finite profile vocabulary;
- distinction gain and distortion loss are heuristics, not external semantic measurements;
- competition currently works at corpus-level profile hints rather than paragraph/claim-level routing;
- local composition does not yet produce a merged but provenance-preserving downstream living graph;
- source-born profiles in this benchmark still descend from one broader relation-genesis family, so genuinely independent operator-family birth remains unfinished;
- external expert semantic validation remains pending.

## Strongest next stage

The next qualitative step is **micro-local operator ecology**: move competition from whole-corpus profile hints down to argument windows / claim clusters. A single work should be allowed to route different passages through different operators, carry unresolved boundaries between them, and then test whether a higher-level synthesis adds information or merely erases local heterogeneity.

The key criterion is no longer “which operator wins on this corpus?” but:

`where does each operator gain purchase, where does it distort, where do domains overlap, and where must the system leave a boundary unresolved?`

## Release ceiling

`0.8.0-alpha.1` is a developer-tested research alpha. Operator competition is an internal source-bounded routing experiment. It is not external semantic validation, philosophical truth, or CORE promotion. `CORE 4.0.0-alpha.1` remains unchanged.
