# Geviert source-resistance regression — DAE 0.6.0-alpha.1

## Purpose

This is an adversarial regression of the `SOURCE-RESISTANCE / OPERATOR-MUTATION 0.2` layer. It tests whether a Heidegger Geviert dossier can force revision of the engine's problem-space when source-central terms are not covered by the curated topic registry. It is a run-bound engineering/philosophical regression, not external semantic validation and not proof of a Heidegger interpretation.

## Failure reproduced from 0.5

The earlier engine reduced the dossier mainly to the legacy constellations `DIACHRONIC_HEIDEGGER` and `TECHNOLOGY_AND_ORDERING`. Central Geviert vocabulary did not control hypothesis formation. This demonstrated procedural nonlinearity without sufficient hermeneutic nonlinearity: traversal varied, but the registry had already decided what could count as a problem.

## 0.6 source-resistance result

The refinery now reports `REGISTRY_BLIND_SPOT`. Twelve source-backed central terms are detected outside the legacy problem-space: `Geviert`, `Göttliche`, `Erde`, `Himmel`, `Sterbliche`, `Ding`, `Ort`, `Ferne`, `Nähe`, `Welt`, `Ereignen`, `Vierung`. Coverage by the curated registry is `0/12` for this regression.

Nine explicit project theses survive corpus routing as literal `claim_statement` candidates instead of being replaced by generic topic meta-theses. They are independently adjudicated. Explicit theses do **not** activate GX7 by themselves.

The mandatory ETY layer emits 26 cards and executes ETY-FULL for all 26 because the dossier explicitly requests ETY stress coverage. Unresolved historical/local fields remain unresolved; ETY-null is retained as a valid result rather than filled by model invention.

## Expert adjudication

Run distribution: `SUPPORTED 1`, `QUALIFIED 9`, `REJECTED 1`, `INSUFFICIENT 2`.

Critical controls behave as intended. `RELATION_FIRST_STRONG` remains `INSUFFICIENT`: a useful representation candidate does not become a strong ontology. `UNIVERSAL_ONTOLOGY` is `REJECTED`: the dossier cannot establish Geviert as a demonstrated universal structure of reality. `METHOD_MUTATION` is only `QUALIFIED` at METHOD scale. Local theses such as `GEVIERT_RELATA_FIRST_REJECTION`, `CO_CONSTITUTIVE_HYPOTHESIS`, `DING_WORLD`, `NEARNESS_DIFFERENCE`, `PLACE_SPACE_REVERSAL` and `GOD_TRANSLATION_FIREWALL` remain source-bounded `QUALIFIED`, not universally supported.

## Living/operator result

Exactly one GX7 mutation is emitted, because mutation is source-forced rather than claim-forced. Candidate: `RELATION_GENESIS_PROFILE_WITH_CO_EMERGENT_RELATA_CANDIDATE`. State: `EXPERIMENTAL_CANDIDATE_NOT_CORE`.

The candidate must preserve five rival representation modes: `RELATA_FIRST`, `RECIPROCAL_RELATION`, `CO_CONSTITUTIVE`, `RELATION_FIRST`, `UNRESOLVED_ONTOLOGY`. It survives only if four regression burdens are met: `RIVAL_UNITIZATION_COMPARISON`, `SOURCE_LINKED_DISTINCTION_GAIN`, `ROLLBACK_PATH_PRESERVED`, `CROSS_CORPUS_REGRESSION`.

The final living graph contains 12 constellations, 347 nodes and 538 edges. These counts show traversal output only; they do not measure philosophical quality. The important change is that source resistance precedes registry closure and can alter the operator ecology without altering Frozen CORE.

## Hermeneutic-writing regression

The primary `PHILOSOPHICAL_FIELD_NOTE.md` no longer repeats the same generic route impulse. Cross-constellation routes preserve the literal target thesis, local source terms, shared operator families, a rival-unitization experiment, counterpressure and a discriminator. This is intended to make narrative nonlinearity semantically consequential rather than decorative.

## Claim ceiling and reopening condition

The regression establishes that the engine can detect and respond to this registry blind spot. It does not establish that relation-genesis is the correct general ontology or that the Geviert reconstruction is philosophically true.

Reopen 0.6 when a substantially different source corpus is available. The next test must ask whether it can force a **different** operator delta and whether the Geviert-derived relation-genesis operator can be retired when it adds no repeatable source-linked distinction.
