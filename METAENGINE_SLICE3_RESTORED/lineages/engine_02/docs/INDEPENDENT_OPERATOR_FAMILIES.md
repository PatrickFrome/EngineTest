# Independent Operator Families — 0.10

## Purpose

Version 0.10 extends source-forced method mutation beyond the relation-genesis family. The central rule is that a source may force a qualitatively different interrogative regime rather than merely a new relation profile.

The first implemented independent family is `PROCESSUAL_HERMENEUTIC_PROFILE`. It is an experimental routing family, not a philosophical ontology and not a CORE promotion.

## Processual signal families

The detector can register source-local pressure around:

- `TEMPORALITY` — sequence, temporalization, before/after, present/future, kairological or process terms;
- `EXPECTATION` — waiting, anticipation, arrival, deferral;
- `ENACTMENT_PRACTICE` — doing, enactment, conduct, ritual or performance;
- `REPETITION_RHYTHM` — repetition, habit, rhythm or recurrence;
- `MATERIAL_MEDIATION` — bodily, material, spatial or artefactual mediation;
- `ABSENCE_WITHDRAWAL` — absence, withdrawal, disappearance or non-availability;
- `TRACE_DISCLOSURE` — trace, indication, disclosure, showing or concealment;
- `ADDRESS_RESPONSE` — address, call, response, answer or being-called.

These cues use Unicode lexical boundaries. Substring coincidence is not sufficient activation.

## Local processual profiles

The first source-born local profiles are:

- `TEMPORAL_ENACTMENT`;
- `PRACTICE_MEDIATION`;
- `ABSENCE_DISCLOSURE`;
- `RESPONSIVE_ENACTMENT`.

A local window may also activate relation-genesis profiles. In that case the local ecology can return `MULTI_FAMILY_LOCAL_PROFILE`; this does not fuse the families into a global meta-ontology.

## Birth rule

A family is not admitted merely because it is listed in a registry. Its origin refinery must contain the required profile and its origin living trace must contain the corresponding source-forced method mutation. The first 0.10 benchmark uses controlled synthetic corpora solely to test this mechanics.

## Epistemic firewall

`source-born family` ≠ `true ontology` ≠ `authorial doctrine` ≠ `CORE`.

A family can be locally useful, coexist with another family, be defeated by a negative control, or remain unserved. The project must preserve abstention when no family is warranted.
