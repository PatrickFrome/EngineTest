# Open-Set Semantic Review Debt — Studio 0.6

The 0.10 open-set engine is intentionally able to propose a new operator family from recurrent source-central terms and micro-local co-occurrence signatures. This is useful for escaping a closed registry, but lexical recurrence is not sufficient semantic evidence.

Every `ADD_OPERATOR` candidate therefore carries a Studio-level review debt before any CORE or universalization claim:

1. **Predicate + polarity** — distinguish assertion from denial and incompatible predications.
2. **Attribution** — separate the author's operative position from quotation, paraphrase, reported speech and opponent positions.
3. **Modality** — distinguish actuality, possibility, necessity, hypothesis and counterfactual use.
4. **Argumentative role** — premise, objection, example, reductio, concession, definition, transition and conclusion must not be treated as equivalent recurrence.
5. **Paraphrase / translation perturbation** — a viable operator should not disappear merely because surface wording changes while the relevant distinction is preserved.
6. **Decoy terminology / negation inversion** — lexical presence without the target role must not activate the family.

This debt does not prevent experimental candidate execution. It prevents a lexical-surface success from silently becoming a semantic or ontological promotion.
