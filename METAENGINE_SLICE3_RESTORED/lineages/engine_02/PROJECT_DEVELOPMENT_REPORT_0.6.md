# Destruktion 4.0 — Project Development Report 0.6

## Revision thesis

Version `0.6.0-alpha.1` addresses a failure discovered by actual engine execution on the Heidegger Geviert dossier. Version 0.5 was nonlinear at the traversal level but could remain hermeneutically linear because source material was first forced through a curated topic ontology. A system can branch indefinitely and still ask only questions it already knows how to recognize.

The 0.6 revision therefore changes the locus of nonlinearity. Nonlinearity is no longer only `operator order → multiple paths`; it becomes `source resistance → revision of problem-space → experimental operator mutation → regression/retirement`.

## Architectural delta

`src/source-resistance.mjs` detects source-backed central terms separately from project claims and ETY stress requests. If the source has sufficient central vocabulary that remains outside legacy topic coverage, the refinery creates `SOURCE_FORCED_REGISTRY_RESISTANCE`. This gives the source a limited right to challenge topic recognition, unitization and relation ontology.

The right is asymmetric. Explicit project theses are preserved and adjudicated, but cannot by themselves mutate the method. ETY stress can force a philological audit card, but cannot by itself establish source centrality. This prevents the source-resistance mechanism from becoming a self-authorizing novelty generator.

`GX7 Source Resistance / Operator Mutation` produces `SOURCE_RESISTANCE → REPRESENTATION_FAILURE → OPERATOR_DELTA`. An operator delta is never a CORE promotion. It has the state `EXPERIMENTAL_CANDIDATE_NOT_CORE` and must retain rollback plus a retirement condition.

## Epistemic nonlinearity

Expert adjudication now preserves literal `claim_statement` values from explicit project theses. Evidence burden depends on scale. A local source-bounded reconstruction may be `QUALIFIED` when local source selectors exist, but cannot become `SUPPORTED` merely through internal thematic coherence. Strong ontology remains blocked by unresolved primary-source burden; universal promotion receives a stricter rejection gate.

This creates an asymmetric epistemic topology rather than a single confidence ladder: discovery can expand the space of candidates, while stronger scales increase evidential burden. A method mutation can be generatively strong (`GG7_OPERATOR_EVOLUTION`) and epistemically weak at the same time.

## Hermeneutic nonlinearity

For relation-sensitive resistant sources the engine keeps multiple representational ontologies live: `RELATA_FIRST`, `RECIPROCAL_RELATION`, `CO_CONSTITUTIVE`, `RELATION_FIRST`, `UNRESOLVED_ONTOLOGY`. The engine is forbidden from treating successful use of `RELATION_FIRST` on one corpus as evidence that relation is ontologically primary.

The field-note renderer now derives cross-constellation routes from literal target claims, local source terms and shared operator families. Each selected route carries a different experiment and discriminator rather than repeating one generic question. The narrative can therefore expose collision among representations instead of merely narrating graph traversal.

## Etymological discipline

ETY-0.2 remains mandatory, but explicit ETY stress is separated from source-resistance. Dynamic unregistered terms can receive source-form cards. When historical derivation, local use or translation residual is unresolved, the output displays ETY-null. The absence of an etymological result is data; it is not a prompt to invent a root story.

## Portability correction

Structural validation now attempts the pinned Ajv package first and falls back to a bundled compatibility validator when package installation or network access is unavailable. The selected backend is exposed in validation provenance. This makes the AI-chat portable project executable in offline environments while preserving the normal pinned dependency path when available.

## Geviert regression

The 0.6 regression detects a `REGISTRY_BLIND_SPOT` with twelve source-backed central terms outside legacy topic recognition, preserves nine explicit project theses, emits 26 ETY cards, and creates exactly one source-forced method-mutation candidate. `RELATION_FIRST_STRONG` remains `INSUFFICIENT`; `UNIVERSAL_ONTOLOGY` is `REJECTED`; method mutation is only `QUALIFIED` at METHOD scale.

This regression is deliberately adversarial: success means not that the project “agrees” with the dossier, but that it can expose its own representational failure and keep several rival repairs live.

## Remaining risk

A self-modifying method can become more dogmatic than a fixed one if every difficult source causes category proliferation. The central risk of 0.6 is therefore **operator inflation**. Cross-corpus regression and operator retirement are not optional future refinements; they are the condition under which source-forced mutation remains epistemically disciplined.

The next stage should test at least one corpus whose resistance is not primarily relation-genesis. The strongest result would be a case where the source forces a different operator delta and simultaneously causes the Geviert-derived delta to be retired. That would demonstrate that the project can learn without merely accumulating lenses.

## Release ceiling

`0.6.0-alpha.1` remains a developer-tested research alpha. Structural conformance, fixity, regression success and internal adjudication are not external semantic validation. Frozen CORE remains unchanged.
