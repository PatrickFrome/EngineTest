## Extended high-volume matrices

### Cache integrity

**131,072** exact typed-state cache keys were generated in parallel. Unique keys: **131,072**. Collisions: **0**. Deterministic duplicate identity remained stable. This validates exact hash-key integrity, not semantic-equivalence caching.

### Router perturbation

**65,536** routing perturbations covered all nine routing domains but still collapsed to only **45 coarse task fingerprints**. This confirms `ROUTER_RESOLUTION_SATURATION`: the current fingerprint is useful for coarse routing but insufficient as a high-resolution empirical task identity.

### Topology structural screening

**16,384** topology screens produced:

- `DYNAMIC_GAIN_TOPOLOGY`: **14,523** selections;
- `DISAGREEMENT_RESOLUTION_TOPOLOGY`: **1,861** selections.

This confirms `TOPOLOGY_SELECTOR_CONCENTRATION`. Forced native tests show all six fixed topology families remain executable, so the concentration is a selector property rather than loss of topology capability.

### Order-4 combinatorial ablation

All **1,820 / 1,820** four-engine removals were evaluated at the frozen-primary layer. Observed claim-graph ranges:

- claim nodes: **5–27**;
- native positions: **13–43**.

The wide range confirms strongly nonuniform higher-order interaction: some four-engine coalitions are much more structurally consequential than others. This is not a global importance ranking because recursive/native contributions are not re-executed in frozen-primary matrices.

### Randomized subset extension

An additional **2,048** randomized frozen-subset tests used a new seed range. Remaining engines ranged from 10 to 15, observed claim nodes from 5 to 27, and `truth_vote_used_count = 0` throughout.
